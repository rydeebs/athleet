# Athleet

A responsive, DNNR-inspired landing-page concept for an endurance athlete sponsorship marketplace.

Run `npm run dev` and open http://localhost:4173. Run `npm run build` for static output in `dist`.

Includes athlete and brand messaging, an interactive fee calculator, accessible FAQs and a downloadable sponsorship brief. This is a frontend concept: it does not publish listings, take payments, create accounts or send form data.
